## Set-up

- 29 real announcements from the dev window (FWP 8, 424B 8, 8-K new 13), 54 true instruments; read through `edgar_pit` at each episode's cut-off.
- One call per document, no hints: the model must list every instrument the document announces. Same prompt, schema-forced JSON, temperature 0, `num_ctx` 8192, first 24,000 characters of the document; qwen3 thinking off.
- Pick rule (§8.5, set in advance): the most accurate model that returns valid JSON on ≥ 95% of documents and never takes more than 30 s on one.
- Truth corrections applied: **7** field fixes on 6 documents ([`manifests/bakeoff_truth_corrections.json`](../manifests/bakeoff_truth_corrections.json)) — where the announcement states a different amount, currency or rate type than the next report (model judgment by Claude, read row by row). Before the corrections: `qwen3:4b` 95%, `llama3.1:8b` 88%, `qwen3:8b` 84% — the same order.
